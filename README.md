# AI 교무실 안내

명지중학교 AI 교무실 교직원 연수 자료(따라하기 · 발표 다시 보기). **우리 학교 교직원용만** 둔다.

> 다른 학교 선생님용 소개(소개 발표·체험 안내·둘러보기·진행 꾸러미)는 2026-10-26부터 따로 — https://ai-office-intro.vercel.app
> (이 저장소의 `intro` 갈래, 베르셀 `ai-office-intro`). 여기 남은 `intro.html`·`tour.html`·`visit.html`·`host.html`은 예전 QR·링크를 새 주소로 넘기는 안내뿐이다.

- 첫 화면: `index.html`
- 교직원: 따라하기 `guide.html` · 연수 발표 `deck.html`(장면 데이터 `scenes.js`)
- 교직원 짧은 연수(약 35분, 전자칠판·시험 날 담임·분실물 함·넵·PC 설치본·AI 버튼): `mini.html`(장면 데이터 `mini-scenes.js` — 연수 발표와 같은 화면 그림·엔진, 칠판 쪽지 그림 `img/board/tmemo.jpg`, 더보기 메뉴 `img/more-tools.jpg`, 넵 대화 비우기 `img/nep-swipe.jpg`·`img/nep-room-menu.jpg`)
- 교실 칠판 왼쪽 아래 단추 줄 확대(`board-btns.js` + `img/board/buttons.png`)는 세 발표의 칠판 장면이 함께 쓴다. 칠판 그림(`img/board/*.jpg`)은 칠판 창 프로그램 모드(?app=1)로 찍어 [숨기기]까지 보인다
- PC 설치본 두 장면은 `pc-scenes.js` 하나를 연수 발표·짧은 연수가 함께 쓴다(그림 `img/pc/desktop.jpg`·`install.jpg`는 이해를 돕는 합성, 창 안 화면은 실제 앱을 설치본 모드로 찍은 것). 따라하기 안내 카드는 `scenes.js`의 `pc`
- 2026-10-24 앱(「AI 해죠」, 유리 물방울 아래 탭)에 맞춰 소개 발표(지금은 intro 갈래)가 쓰던 휴대폰 화면 52장은 아래 탭을 체험판에서 찍은 새 탭으로, AI 화면 머리를 「AI 해죠 · 무엇이든 해 달라고 하세요…」로 덧그렸다(자리는 그대로라 동그라미 R()도 그대로). PC 그림 왼쪽 위 단추는 「AI 해죠에게 부탁하기」.
- 2026-10-25 AI 해죠 첫 화면 정리(AI 배지 제목·「○○ 선생님, 무엇을 도와드릴까요?」·추천 질문 줄·＋ 메뉴 입력 줄)에 맞춰 AI 화면 22장(`img/ai-*.jpg`, 새로 `ai-plus`·`ai-typed`)(소개 발표용 사본은 intro 갈래)을 새 코드로 다시 찍었다. 아래 탭만 체험판의 새 탭으로 덮었고, 동그라미 자리는 `img/rects.js`에 새로 잰 값.
- 2026-10-25 캡처 사본(/home/user/mjms-shot)을 운영 main(24b0457)까지 맞추고(가짜 백엔드·외부 호출을 고친 8개 파일은 그대로), 예시 데이터에 띵동(계정·종 그림·보강 모집·당번 넵)과 홍길동이 전체 교직원에게 보낸 일정 넵을 더해 넵 화면 29장을 다시 찍었다(새 아래 탭·카드의 「전달」이 그대로 찍힘). 새 그림: `nep-fwd`·`nep-fwd-org`·`nep-add`·`nep-cal`·`alerts-done`. 교직원 연수에만 쓰던 그림 12장(자료실·더보기·넵)의 아래 탭도 새 탭으로 덮었다. 받은 탭 그림의 「교목실」을 지운 사본은 intro 갈래에만 둔다.
- 발표 엔진 `deck.js`(1920×1080 무대, Web Animations), 휴대폰 틀 `phone.css`, 소리 `sound.js`, 글꼴은 앱과 같은 프리텐다드(`fonts/pretendard`, OFL)
- 휴대폰 화면 `img/*.jpg`(412×864 기준, 2배)은 **실제 앱을 예시 데이터(지어낸 학교·이름)로 띄워 찍은 것**이다. 실제 교직원·학생 이름은 없다. 동그라미 자리는 찍을 때 잰 값 `img/rects.js`(`R(화면, 키)`).
- 교실 칠판 그림 `img/board/*.jpg`(점심시간 분실물 띠는 `lunch.jpg`), PC 화면 `img/desk/*.jpg`(진도 지도 「한 달」·「주별 표」는 `pg-*.jpg` — 따라하기 안내 카드에는 `figs`로 붙인다). `img/board/inclass-composite.jpg`는 이해를 돕는 합성 그림이다.
- 가장 큰 핵심은 **AI에게 말로 부탁하기**(말하기 → 카드 → 누르기). 연수 발표는 기본 설정 다음 2부가 AI이고 부마다 끝에 「AI로 하면」 장면(`aiWay`)이 있다. `deck: false` 장면은 발표에서 빼고 따라하기 안내에만 싣는다.
- 「내일 해 볼 부탁 열 문장」은 `asks.js` 하나에서 — 연수 발표·따라하기·첫 화면이 같은 목록을 쓴다(intro 갈래에도 같은 사본)(앱에 실제로 있는 답·카드만).
- 넵은 10월 18일 개편(조직도·받은·보낸 탭, 보낸 선생님별 방, 메시지·넵 받기·완료 받기·파일 받기)에 맞춰 4부를 다시 짰다: 넵 네 가지 → 세 탭(`nepTabs`) → 실습 9 나에게 메모 → 조직도로 보내기 → 실습 10 방에서 처리·답장 → 보강 모집 → AI로 넵 초안.
